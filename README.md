# Карточка для донатов

Визитка автора с QR-кодами и переключением способов перевода. Помещается на любой экран без прокрутки.

## Под нового автора

```bash
cp .env.example .env
```

Заполни `.env`: имя, ссылку на канал, аватарку и реквизиты. Способ с пустым значением не показывается. Аватарку положи в `public/` и укажи её путь. После правки перезапусти сервер.

На хостинге задай те же переменные в его настройках: файл `.env` в git не попадает.

## Запуск

```bash
npm install
npm run dev
```

## Адреса

| Адрес | Что делает |
| --- | --- |
| `/` | Обычная карточка |
| `/?m=ton` | Открывает нужный способ: `sbp`, `yoomoney`, `yoomoney-sbp`, `trc20`, `bep20`, `ton` |
| `/?stream` | Для OBS: прозрачный фон, без кнопок, способы сменяются каждые 12 секунд |
| `/?stream=20` | То же, смена каждые 20 секунд (минимум 3) |

Клавиши `1`–`6` и `←` `→` переключают способ.
